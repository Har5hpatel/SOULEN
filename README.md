# SOULEN

> One mind. Online or offline.

SOULEN is a personal hybrid AI assistant designed for PC and mobile. It combines offline functionality with online AI intelligence, aiming to create a seamless assistant capable of answering questions, performing tasks, automating workflows, and interacting with devices.

The goal is to build something beyond a chatbot — a personal AI that can assist with everyday tasks, operate my PC, interact with my phone, and remain useful even without an internet connection.

## Vision

- **Hybrid Intelligence** — Offline functionality when disconnected and online AI when internet access is available.
- **Multi-AI Support** — Connect with cloud AI providers such as Gemini, ChatGPT, and Grok.
- **PC Automation** — Open applications, manage files, control system functions, and automate tasks.
- **Voice Interaction** — Wake word detection, speech recognition, and natural voice responses.
- **Phone Integration** — Control supported Android functions and perform specific tasks remotely.
- **Memory** — Remember useful information, preferences, and previous interactions.
- **Modern HUD Interface** — A futuristic holographic interface inspired by Iron Man's JARVIS.

## Planned Tech Stack

- Python — Core logic and assistant engine
- Ollama — Optional local AI models
- Gemini / ChatGPT / Grok APIs — Online intelligence
- Faster-Whisper — Speech recognition
- Piper — Offline text-to-speech
- OpenWakeWord — Wake word detection
- Tauri — Lightweight desktop interface
- ADB / Termux — Android integration
- SQLite — Local memory and storage

## Roadmap

- [ ] **Phase 1 — Core Brain:** Command processing, AI conversations, and tool calling.
- [ ] **Phase 2 — Offline Mode:** Local commands, alarms, timers, app launching, and basic system controls.
- [ ] **Phase 3 — Online Intelligence:** AI provider integration, internet search, and fallback routing.
- [ ] **Phase 4 — Voice:** Wake word, speech-to-text, and text-to-speech.
- [ ] **Phase 5 — PC Control:** Application control, file operations, browser automation, and system monitoring.
- [ ] **Phase 6 — Memory:** Personal preferences, conversation history, and document retrieval.
- [ ] **Phase 7 — HUD Interface:** Animated holographic UI, floating overlay, and system dashboard.
- [ ] **Phase 8 — Phone Integration:** Android control, notifications, and task automation.
- [ ] **Phase 9 — Advanced Capabilities:** Proactive assistance, multi-step tasks, and smart home integration.

Designed with lightweight components and efficient resource usage in mind.

## Development Philosophy

SOULEN is being built step by step, experimenting with different technologies, learning, and improving along the way. AI tools are used as coding assistants, not substitutes for understanding the code.

This is a personal project, and its capabilities will evolve over time.
